随笔作者：Murphy

语言是世界的投影，但人是否能够被自己的语言充分投影？

语言是坍缩的。

我知道这是一个激进的暴论，但是请听我说完。

第一次坍缩发生在语言出现以前

1960 年，Charles Hockett 把语言能够指向不在场之物的能力概括为离位性。这件事今天听起来几乎理所当然，但把它放回早期智人的生活里，事情就显得相当惊人。猎物已经离开视野，仍然可以告诉同伴它昨天经过哪片河谷，语言第一次让不在场的东西拥有了改变当下的力量。后来 Michael Tomasello 把人类的特别之处归结为共同意图，语言无法凭空制造这种能力，却极大扩张了这种共同空间，于是人类文明开始具有累积性。

但语言并不是无损的。1976 年，Eleanor Rosch 等人在自然类别的研究中发现，人会稳定地优先使用一个基本层级来分类事物。同一个对象可以是家具，可以是椅子，也可以继续细分成某一种具体的椅子，比如办公椅或者餐椅，而“椅子”通常是人最自然使用的层级。这个层级保留了大量同类对象的共同属性，同时把许多具体实例之间的差异留在了类别之外。

进入记忆以后，经验继续变化。

比如早在 1932 年，Frederic Bartlett 就提出回忆不是重播而是重构，虽然相关研究都快被自媒体博主给讲烂了，但我还是硬着头皮提一下吧。

另外还有08 年的一个实验，Papafragou 等人让英语和希腊语使用者观看同样的运动事件，记录他们在开口描述以前的眼动。单纯观看时，两组人的注意方式基本相似，一旦准备说话，他们就会更快地注意自己母语通常需要编码的那部分信息。

哪怕尽可能诚实地描述一段经历，进入语言的也只是人脑形成的表征，而非现实本身。

所以在模型接收到第一个 token 以前，现实已经在人脑里坍缩过一次。

第二次坍缩发生在自我解释

2005 年，Petter Johansson 等人让参与者从两张人脸中选出自己认为更有吸引力的一张，随后偷偷把其中部分结果调换。

有意思的是，当研究者请他们解释为什么做出这个选择时，他们仍然能够认真说出理由。有人谈论眼神，有人讨论气质，还有人指出某个自己喜欢的面部特征。Johansson 把这种现象称为 choice blindness。

这件事比撒谎麻烦得多，因为参与者并不一定知道自己说错了。

早在 1977 年，Nisbett 和 Wilson 就提出，人被要求解释自己的判断和行为时，未必是在读取一份已经存在的因果记录。很多时候，我们会调用已有的理论，判断什么原因通常能够造成眼前这个结果。1990 年，Ziva Kunda 在关于 motivated reasoning 的综述中进一步指出，人的推理并不完全与欲望分离。当我们希望一个结论成立时，这种倾向会影响我们调用哪些记忆，如何评价已有的信息，又把什么看做可信的预兆。

但还有一种变化根本不需要如此迂回，人类的确拥有说谎的能力。

正如一个人表现出生气，未必是愤怒真的已经强烈到自然流露。人的一句自我解释真的能被当成行为本身的原因吗，人类的谎言和欲言又止隐藏着怎样的目的？在行为科学里，相同的topography并不意味着相同的function。

但这里有必要把谎言从犯罪现场里拿出来。1996 年，DePaulo 等人让参与者连续记录日常互动中的谎言，发现日常谎言并不只是为了获得实际利益，相当多和自我呈现以及保护别人，避免冲突有关。

避免冲突这个我尤其同意，夸妈妈做的饭好吃，并不意味着我真的没有味觉。

第三次坍缩发生在时间里

语言当然能够描述前因后果，正如小说可以展开一个角色数十年的命运，但描述和还原是两个尺度。

1981 年，Skinner 在 Selection by Consequences 中把选择放到三个尺度上。自然选择改变物种，行为的后果改变个体一生中某些行为再次出现的概率，文化则在更长的时间里筛选能够延续的实践。三个过程共享一个很古老的结构，生命不断产生变异，现实再用后果进行选择。

从这个意义上说，生命并不是沿着时间排列的一串静止事实，可人最终讲述的往往只是其中几个节点。

Olivier Jeunehomme 和 Arnaud D’Argembeau 对真实生活事件的研究发现，情景记忆并不会按照经历原有的时间尺度保存经验，而是会出现明显的时间压缩。

2007 年，Jeffrey Zacks 等人在 event segmentation theory 中也总结了一个基础现象。人在经历连续活动时，会自然地把它分割成一个个事件，这种切分当然是必要的，未经组织的感官堆积几乎没有信息量，但他们的确再次对信息传输造成了折本。

我把这种损失叫作第三次坍缩。

洞穴寓言

我并不是说语言不好，相反我非常喜欢阅读和写作，只是影子的伟大和它的损失来自同一个地方，当它发明了一种形式去共享那些原本不能被共享的经验时，就会因此不得不舍弃那些无法进入这种形式的部分。

我觉得这就是洞穴寓言的精妙之处，当人类因为学会辨认影子而从猿猴变成了智人，是否又需要因为想踏入文明的下一个尺度而学会直视那些阳光直射的地方呢？直直直吱吱吱，感觉这篇文章像老鼠写的，我真的非常讨厌一句话里出现两个同样的字，但我实在找不到合适的词汇来替代“直视”和“直射”，总而言之，人与人与计算机之间必须直接沟通。

现下大模型的向量只在它自己的表征空间里才有意义，但如果未来的脑机接口能够建立一种经过长期适应的共享表征，让一部分内部状态不需要被翻译成自然语言就能进行传递，那么我们可能会迎来一个真正的交互跃迁时刻。

输出确实是一个梳理的过程，很多时候我脑子是乱的，写出来就好了。但这样一个纯然的离开了语言与文字的世界是什么样的呢？希望人类走出洞穴的时刻在我有生之年到来。
